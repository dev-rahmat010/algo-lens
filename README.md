# 🧠 AlgoLens — AI Code Visualizer & Complexity Analyzer

AlgoLens is an interactive developer tool that parses algorithm source codes, evaluates their Time & Space Big-O complexity metrics, and visually animates step-by-step code executions.

---

## ✨ Key Features
- **Visual Execution Stage:** Real-time visual tracking of data structures (such as sorting elements and tracking swaps/comparisons dynamically).
- **Big-O Complexity Metrics:** Instant breakdown of Time $O(n^2)$ and Space $O(1)$ footprints.
- **AI Architecture Log:** Simulated AST (Abstract Syntax Tree) diagnostics and optimization recommendations.
- **Preset Algorithms:** Quick-load options for algorithms like Bubble Sort and Linear Search.

---

## 🛠️ Tech Stack
- **Frontend:** Vanilla JavaScript, HTML5, CSS3
- **Styling:** Tailwind CSS (CDN-driven reactive utility classes)
- **Icons:** Lucide UI Icons
